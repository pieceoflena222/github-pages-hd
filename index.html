실습 1

업무 언어로 시작하는 바이브코딩

코드를 바로 요청하지 않고, AI가 기획자처럼 질문하며 웹페이지 설계안을 먼저 정리하도록 지시하는 시작 프롬프트입니다.

프롬프트 
나는 [생산 차질 원인을 분석하는 업무]를 더 편하게 할 수 있는 웹페이지를 만들고 싶습니다.
사용할 데이터는 [엑셀/CSV 파일]이고,
최종적으로 [주요 현황과 문제 원인을 한눈에 확인]하고 싶습니다.
아직 코드를 만들지 마세요.
내 업무에 실제로 필요한 웹페이지가 되도록 당신이 기획자처럼 필요한 사항을 먼저 질문해주세요.
질문은 한꺼번에 많이 하지 말고 가장 중요한 질문부터 하나씩 진행해주세요.
가능한 질문은 내가 직접 문장을 입력하지 않아도 되도록 객관식 선택지로 만들어주세요.
사용 중인 환경에서 지원된다면 선택지를 버튼처럼 직접 클릭해서 답할 수 있는 클릭형 방식으로 제시해주세요.
- 한 번에 질문 1개
- 선택지는 가능하면 3~5개
- 잘 모르겠어요 / 추천해주세요 선택지도 필요한 경우 포함
- 내 답변에 따라 다음 질문을 달리해주세요.
- 객관식으로 해결하기 어려운 내용만 짧게 추가 질문해주세요.
- 개발 용어보다 실제 업무 담당자가 이해하기 쉬운 표현을 사용해주세요.
충분한 정보가 모이면 코드를 바로 작성하지 말고 먼저
① 필요한 기능
② 화면 구성
③ 데이터 분석 방식
④ 꼭 필요한 예외처리
를 정리한 웹페이지 설계안을 보여주세요.
내가 설계안을 검토하고 "좋아, 만들어줘"라고 말하면 그때 최종 웹페이지 코드를 작성해주세요.

TIP — 대괄호 [ ] 안의 내용은 실제 담당 부서의 업무에 맞게 바꿔서 입력하세요.

실습 2

설계안 확정 후 웹페이지 구현 요청

AI가 제시한 설계안을 검토한 뒤, 실제 동작하는 HTML 대시보드로 완성해달라고 요청하는 프롬프트입니다.

프롬프트
실습 파일 다운로드 
좋아요. 이 설계대로 만들어주세요.
별도 프로그램 설치 없이 PC에서 실행할 수 있도록 하나의 HTML 파일로 완성해주세요.
파일을 업로드하면 브라우저 안에서 처리되도록 하고, 디자인은 실제 회사에서 사용할 수 있는 전문적인 업무용 대시보드로 만들어주세요.

완성된 대시보드가 만들어지면 실습파일1을 업로드해 실제로 동작하는지 확인해보세요.

실습 3

사용해보고, 내 업무에 맞게 고도화하기

완성된 웹페이지를 써본 뒤, 실제 피드백을 주듯 세 가지 방향으로 다듬어달라고 요청하는 예시 프롬프트입니다.

예시 1
필요한 기능만 남기고 추가하기 
전체적으로 잘 만들어졌어.
시간대 분석은 우리 업무에서는 필요 없으니 빼줘.
대신 설비별 정지시간 TOP 5를 추가해줘.
가장 중요한 생산차질 원인이 첫 화면에서 더 잘 보이게 해줘.
기존에 잘 작동하는 기능은 그대로 유지해줘.
예시 2
첫 화면을 더 보기 쉽게 
차트가 많아서 처음 봤을 때 조금 복잡해.
핵심 KPI 4개와 중요한 차트 3개만 첫 화면에 보여주고, 나머지는 상세보기로 접어줘.
문제가 큰 항목은 한눈에 구분되게 강조해줘.
예시 3
실제 사용할 때 불편한 부분 개선하기 
파일을 잘못 올렸을 때 바로 다시 업로드할 수 있는 버튼을 추가해줘.
데이터 형식이 맞지 않을 때는 단순히 오류라고 하지 말고, 어떤 항목을 확인해야 하는지 쉽게 안내해줘.
처음 사용하는 직원도 어렵지 않게 사용할 수 있게 다듬어줘.
실습 4

데이터를 읽고 설명하는 '인사이트 기능' 추가하기

외부 API 없이, 업로드된 데이터와 계산 결과만으로 질문에 답하는 '데이터 질의 도우미'를 대시보드에 추가하는 프롬프트입니다.

프롬프트 
현재 완성된 대시보드에 '데이터 질의 도우미' 기능을 추가해주세요.
생성형 AI나 외부 API는 사용하지 않고, 현재 업로드된 데이터와 계산 결과만 이용해주세요.
대시보드 하단에
- 가장 큰 차질 원인은?
- 가장 영향이 큰 라인은?
- 미분류 비율은?
- 최근 증가한 항목은?
- 보고서 핵심 포인트는?
버튼을 만들어주세요.
버튼을 클릭하면 실제 계산값과 비율을 근거로 짧은 분석 문장을 보여주세요. 데이터로 확인할 수 없는 원인이나 대책은 추측하지 마세요.
각 분석 결과에는 '보고서에 포함' 기능을 넣고, 선택한 문장은 기존 보고서의 '종합 분석 및 주요 확인사항'에 자동으로 반영해주세요.
비교할 데이터가 부족한 경우에는 임의로 판단하지 말고 비교 가능한 데이터가 충분하지 않습니다라고 안내해주세요.
기존 대시보드·보고서·A4 인쇄 기능은 그대로 유지한 상태에서 최종 전체 코드를 수정해주세요.
실습 5

대시보드를 보고서까지 확장하기

대시보드에서 선택한 핵심 데이터를 실제 제출·출력이 가능한 업무보고서 형식으로 재구성하는 프롬프트입니다.

프롬프트 
현재 완성된 웹페이지와 보고서 생성 기능을 유지하면서, 보고서 부분을 실제 기업·기관에서 제출하거나 출력해 사용할 수 있는 수준의 고품질 업무보고서 형태로 전면 고도화해 주세요.

중요한 목적은 단순히 대시보드를 A4 화면에 옮기는 것이 아닙니다.

대시보드에서 사용자가 선택한 핵심 데이터와 차트를 실제 보고서 문법에 맞게 재구성하여, 읽는 사람이 현황 → 핵심 결과 → 원인 → 관리 필요사항을 빠르게 이해할 수 있는 문서로 만드는 것이 최종 목표입니다.

⚠ 원본 강의안에는 이 문단 뒤에 세부 항목 3개가 불릿(●●●)으로 표시되어 있으나 내용이 비어 있습니다. 임의로 채우지 않고 원문 그대로 옮겼습니다 — 강의안 원본 확인이 필요합니다.

실습 6

PC에서 모바일까지, 반응형 웹페이지로 확장하기

완성된 웹페이지를 스마트폰·태블릿에서도 편하게 쓸 수 있도록 반응형으로 확장하는 프롬프트입니다.

프롬프트 
PC뿐 아니라 스마트폰과 태블릿에서도 편하게 사용할 수 있도록 반응형 웹페이지로 구성해주세요.
